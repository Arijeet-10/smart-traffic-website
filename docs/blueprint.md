# **App Name**: SmartOPT

## Core Features:

- West Bengal Data Architecture: Implement the hierarchical 'citiesData' JavaScript object, pre-populated with all specified cities and junctions across West Bengal, each with realistic traffic parameters, adhering strictly to the defined structure.
- Traffic Data Simulation Engine: Simulate real-time fluctuating data for vehicle counts, AQI, and signal timers based on predefined junction parameters, incorporating random fluctuations, an auto-refresh system (5-7 seconds), AQI classification, and logical constraints.
- Adaptive Traffic Signal Logic: Implement a 'tool' that dynamically adjusts (simulated) traffic signal timings at each junction based on the real-time (simulated) AQI and vehicle count, mimicking an AI-powered control system.
- Interactive Dashboard & Visualizations: Present real-time traffic analytics using a card-based UI for vehicle count, AQI status, signal timer, road condition, and active nodes, with interactive dropdowns for city and junction selection.
- Real-time UI Updates & Responsiveness: Dynamically refresh dashboard data every 5-7 seconds with smooth transitions, ensuring a fully responsive and mobile-friendly user experience across all devices.
- Thematic UI with Dark/Light Mode: Offer a clean, modern user interface with a configurable dark/light mode toggle and ensure optimal text readability and contrast in both themes.
- Informative Landing Page: Structure a comprehensive landing page including sections for 'About', 'Features', 'Live Dashboard' (with a link to the main dashboard), 'How it Works', 'Benefits', 'Tech Stack', and 'Future Scope'.

## Style Guidelines:

- Primary color: A deep, professional blue-violet (#1E1EAD), symbolizing efficiency and intelligence, to provide strong contrast in a light scheme.
- Background color: A subtle, cool light grey (#F0F0F5), tinted with the primary hue for visual consistency and a clean base.
- Accent color: A vibrant, clear blue (#4799EB) to highlight interactive elements, calls-to-action, and key data points, providing distinct contrast against primary and background colors.
- Headline and body font: 'Inter', a grotesque-style sans-serif for its modern, objective, and highly readable characteristics, suitable for both data heavy displays and descriptive text.
- Utilize simple, clear outline icons for traffic signals, vehicles, sensors, data points, and UI controls to maintain a modern and uncluttered aesthetic.
- Employ a card-based layout for dashboard elements, ensuring content is organized and digestible. The overall design will be responsive to support seamless viewing on various screen sizes, including mobile devices.
- Integrate minimal animations, primarily hover effects for interactivity and smooth transitions for data updates to convey real-time responsiveness without visual clutter.
